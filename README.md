To run, go to `launch.json` and `Run`, then `Run Extension`. Then open the repository you want to explore and highlight a line of code and press `Cmd`+`Opt`+`E` and you will be prompted to input your OpenAI API key, then a window will pop-up with a description of the line highlighted. 

To not input your API key every time, you can also set it in your VS Code JSON settings as `"lineExplainer.apiKey": "sk-proj-your-actual-openai-api-key-here"`.
